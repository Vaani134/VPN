
🔒 Python VPN Client Simulator

Hey there 👋
This is my Python-based VPN Client Simulator.
The goal of this project is to understand VPNs — how they connect, how data can be encrypted, and how files can be shared securely over a simulated network.

It’s a learning project, not a production-ready VPN. Think of it like a playground where I explore networking and security concepts with Python. 🚀

🌟 Features

🌐 Connect & disconnect to a simulated VPN

🔑 Encrypt and decrypt data/messages

📁 Share files securely through the tunnel

📊 See connection status & logs

💻 Clean and simple interface (Web-based or CLI)

🛠️ Built With

Language: Python 🐍

Libraries: socket, ssl, cryptography, Flask etc.

Frontend: HTML/CSS

Tools: GitHub Desktop for version control


🚀 Getting Started
Install dependencies
pip install -r requirements.txt

Run the project
python app.py

🧪 Testing it

Run the client

Hit Connect → “VPN connected” will appear

Try sending a file/message → it will be encrypted + decrypted

Disconnect when done
